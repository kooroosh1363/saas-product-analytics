# Data Source & Provenance

## Upstream source

DA-05 uses the public **Lightdash SaaS Demo** repository maintained by Lightdash as an externally sourced product-analytics dataset.

Upstream repository: `lightdash/lightdash-demo-saas`

The upstream README describes a SaaS-style hierarchy of accounts, deals, users, and product-usage tracks, including user activation timestamps and event-level product activity such as successful logins, generated reports, file downloads, workspace creation, API usage, and integration failures.

## Important provenance guardrail

This portfolio does **not** claim that the dataset is production customer data from a real SaaS company. It is an official public demo dataset intended to model a SaaS/customer journey. It is valuable here because it is externally sourced, multi-table, event-level, and not generated by this repository.

The upstream repository currently does not expose an explicit standalone dataset license file at its root. Therefore this project does **not redistribute the upstream raw CSV files**. The acquisition script downloads the files from their original public repository at runtime. Users should review upstream terms before reuse outside analysis/education.

## Files used

- `accounts_raw.csv` — account/company attributes
- `deals_raw.csv` — sales/deal and plan attributes
- `users_raw.csv` — user creation and login timestamps
- `tracks_raw.csv` — product-usage event log

## Reproducibility

Run:

```bash
python -m src.download_data
```

Raw files are downloaded into `data/raw/`, which is Git-ignored. Derived analytical outputs are written to `outputs/` and are also ignored unless intentionally curated for documentation.

## Why this source was selected

Compared with a self-generated synthetic dataset, this source adds external schema interpretation, multi-table joins, timestamp cleaning, event taxonomy handling, user/account grain decisions, and product-usage ambiguity. That is the skill progression DA-05 is intended to demonstrate.
