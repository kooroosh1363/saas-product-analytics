# DA-05 — SaaS Product Analytics

This repository is being developed as a portfolio-grade SaaS product analytics case study focused on activation, engagement, retention, churn, feature adoption, plan performance, and product-growth insights.

## Data strategy

This project will use a real/public dataset where provenance and licensing are verifiable. Large raw files will not be committed to Git. Instead, the repository will document the source, license, schema, and reproducible acquisition/preparation steps.

## Planned scope

- Real/public SaaS or product-usage dataset with documented provenance
- Raw vs processed data separation
- Data quality and cleaning report
- Activation and engagement metrics
- Feature adoption analysis
- DAU / WAU / MAU and stickiness where supported by the source data
- Retention and churn analysis
- Plan / segment performance
- Product-growth insights and recommendations
- Tests, reproducible execution, and CI

> Full project development will happen on a dedicated branch before final review and merge.
